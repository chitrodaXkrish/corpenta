# Earth texture

`earth-natural-color.jpg` is a 1024 × 512 local resize of the Three.js Earth diffuse texture `earth_atmos_2048.jpg` from the official Three.js examples texture collection. The source texture is identified by public NASA Visible Earth references as NASA Blue Marble imagery (public domain).

Source: https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg
Texture is loaded locally by the homepage globe; no third-party image request is made at runtime.
